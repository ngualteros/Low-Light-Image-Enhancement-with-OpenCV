
# Image Dataset

## Source

The original academic laboratory used four images identified as samples from the Dark Face low-light image dataset.

## Required Files

Place the following files locally inside `data/images/`:

- `1050.png`
- `1051.png`
- `1052.png`
- `1053.png`

## Directory Structure

```text
data/
├── README.md
└── images/
    ├── 1050.png
    ├── 1051.png
    ├── 1052.png
    └── 1053.png
```

## Usage

The notebook reads the image files using OpenCV.

Original images are excluded from Git version control until their redistribution conditions are confirmed.

## Notes

The experiments use two color images and two grayscale representations.

Results may vary depending on the input images and transformation parameters.
