
# Low-Light Image Enhancement with OpenCV

## Overview

This project explores classical digital image processing techniques for enhancing and analyzing low-light images.

Developed as part of my Master's degree in Artificial Intelligence at Universidad Internacional de La Rioja (UNIR), the project applies different pixel intensity transformations to images captured under challenging lighting conditions.

The implementation uses Python, OpenCV, NumPy, and Matplotlib to compare image transformations and explore their effects on visual appearance and pixel intensity statistics.

A complementary MATLAB implementation is also included.

## Objectives

- Explore digital image enhancement techniques.
- Analyze images with low illumination.
- Apply brightness and contrast adjustments.
- Investigate histogram equalization.
- Perform arithmetic operations on image matrices.
- Apply gamma correction.
- Explore logarithmic transformations.
- Generate image negatives.
- Compare image intensity statistics.
- Visualize the effects of different transformations.

## Image Processing Techniques

### 1. Brightness and Contrast Adjustment

The notebook uses OpenCV's `convertScaleAbs()` function to transform pixel intensities.

The original implementation applies:

- Contrast parameter: `alpha = 1.5`
- Brightness parameter: `beta = 50`

The objective is to explore how intensity scaling and brightness offsets affect image visibility.

### 2. Histogram Equalization

Histogram equalization is applied to grayscale representations of the input images.

The technique redistributes pixel intensities to improve global contrast.

OpenCV function:

```python
cv2.equalizeHist()
```

### 3. Arithmetic Operations

The notebook explores arithmetic operations on image matrices:

- Addition
- Subtraction
- Multiplication
- Division

These operations demonstrate how manipulating pixel values affects image appearance.

Not every arithmetic transformation necessarily improves image quality.

### 4. Gamma Correction

Gamma correction is implemented using a lookup table and OpenCV's `LUT()` function.

The original experiment uses:

```python
gamma = 1.5
```

A power-law transformation is applied to the pixel intensity values.

### 5. Logarithmic Transformation

A logarithmic intensity transformation is implemented with NumPy.

The technique changes the distribution of pixel values and can emphasize differences in darker intensity ranges.

### 6. Image Negatives

Image negatives are generated by subtracting each pixel value from 255.

This transformation is included as an image-processing experiment rather than a dedicated low-light enhancement technique.

### 7. Image Statistics

The notebook calculates:

- Mean pixel intensity
- Median pixel intensity
- Pixel intensity variance

These statistics are used to explore differences between original and transformed images.

They do not, by themselves, establish perceptual image quality improvements.

## Limitations

- The analysis uses only four sample images.
- Results are primarily based on visual comparisons.
- No quantitative perceptual image quality evaluation is implemented.
- Histogram equalization is applied to grayscale images.
- Some color-space conversions require cleanup.
- The notebook uses hardcoded image paths.
- The implementation is an academic image-processing experiment, not a production image enhancement application.
